# 🏛️ DCW-SETIF — المنظومة الرقمية الشاملة للرقابة والتفتيش الميداني
### مديرية التجارة الداخلية وضبط السوق الوطنية لولاية سطيف — الجمهورية الجزائرية الديمقراطية الشعبية

> **المستودع الموحد (Unified Monorepo)**: يجمع بين الخادم السحابي وقاعدة البيانات (Backend) وتطبيق الرقابة والتفتيش الميداني متعدد المنصات (Frontend Flutter).
> **المنصة السحابية الحية (Live Render Web App)**: [dcw-setif-tracker.onrender.com](https://dcw-setif-tracker.onrender.com)
> **الخادم السحابي الحي (Live Render API)**: `https://drh-setif-api.onrender.com/api`
> **حالة المنظومة**: ✅ `v3.6.0-authentic-only` — تدقيق واختبار حي ميداني ناجح 100% على السحابة، متوافق ومتجاوب بالكامل مع كافة شاشات الهواتف المحمولة والحواسيب.

## 📁 هيكلية المستودع الموحد (Monorepo Architecture)

```
DCW-SETIF/
├── 📁 backend/                # خادم الـ API وقاعدة البيانات (Node.js, Express, PostgreSQL)
│   ├── server.js              # نقطة انطلاق الخادم والمسارات السيادية
│   ├── src/                   # مسارات المصادقة، الحضور، المعاينات، والخصومات
│   ├── public/                # واجهة الويب الجاهزة للنشر السحابي (v1.0.16+17)
│   └── package.json           # الحزم والاعتماديات
│
├── 📁 tracker/                # تطبيق الرقابة والتفتيش الميداني (Flutter / Dart)
│   ├── lib/                   # شاشات المفتش، رئيس المصلحة، مكتب المستخدمين، والمدير
│   │   ├── screens/           # لوحات التحكم التفاعلية المتجاوبة مع الهواتف والحواسيب
│   │   ├── services/          # خدمات الـ API، والتقارير PDF، والمزامنة الذكية بدون إنترنت
│   │   └── utils/             # الثوابت، المقرات الـ 8، والهوية البصرية الملكية
│   ├── android/               # إعدادات حزمة الأندرويد APK
│   └── pubspec.yaml           # تبعات Flutter
│
├── 📁 docs/                   # الوثائق الإدارية والتقنية
│   ├── DCW_SETIF_DIRECTOR_MANUAL.pdf          # الدليل الرسمي الشامل للمدير الولائي
│   ├── DIRECTOR_MANUAL_PRESENTATION.html      # العرض التقديمي التفاعلي للمنظومة
│   └── OFFICIAL_CREDENTIALS.md                # بيانات الحسابات المعتمدة الرسمية
│
├── 📄 package.json            # إعدادات التشغيل التلقائي من الجذر لمنصة Render
├── 📄 AGENTS.md               # دليل الوكيل والمطور والبروتوكولات الصارمة وسجل المعالم
└── 📄 README.md               # دليل المنظومة والتشغيل
```

## 🏛️ المقرات الثمانية المعتمدة للبصمة الجغرافية الرسمية

1. **المقر الرئيسي للمديرية الولائية**: حي المعبودة، سطيف (`36.1900575, 5.3990134` — نصف القطر: 250م).
2. **المفتشية الحدودية لمراقبة الجودة**: مطار 8 ماي 1945 الدولي، عين أرنات (`36.1781, 5.3247` — نصف القطر: 1200م).
3. **المفتشية الإقليمية للتجارة بالعلمة**: وسط العلمة (`36.1554, 5.6908` — نصف القطر: 1200م).
4. **المفتشية الإقليمية للتجارة بعين ولمان**: القطاع الجنوبي (`35.9189, 5.2978` — نصف القطر: 1200م).
5. **المفتشية الإقليمية للتجارة ببوقاعة**: القطاع الشمالي والغربي (`36.3325, 5.0886` — نصف القطر: 1200م).
6. **الملحقة التجارية بعين آزال**: جنوب الولاية (`35.8686, 5.4667` — نصف القطر: 1000م).
7. **الملحقة التجارية بعين الكبيرة**: شمال الولاية (`36.3639, 5.5003` — نصف القطر: 1000م).
8. **الملحقة التجارية بعين أرنات**: غرب الولاية (`36.1833, 5.3167` — نصف القطر: 1000م).

## 📱 التصميم المتجاوب ودعم شاشات الهواتف المحمولة (Mobile Responsive UI)
* **دعم شاشات الهواتف بكافة مقاساتها**: تم ضبط بطاقات الرصد الآلي للمخالفين وقوائم الاستفسارات لتتكيف تلقائياً مع الشاشات الضيقة عبر نظام المستويين (`Two-Tier Responsive Layout`).
* **حماية النصوص من التداخل والقص**: تم استخدام مكونات `Wrap` لضمان عدم تصادم أسماء الموظفين مع شارات الغياب أو التأخر، وتوزيع أزرار الإجراءات ("توجيه استفسار" و"تغاضي / عذر") بعرض متناسق وسهل اللمس.

---

## 📡 محرك العمل بدون اتصال (Offline Engine)
* **الحفظ المحلي المشفر**: عند انعدام الإنترنت في المقرات أو في مستودعات المعاينة الميدانية، تُخزن العمليات فورياً في الهاتف مع إحداثيات الـ GPS والتوقيت الدقيق للحظة البصمة.
* **المزامنة الصامتة التلقائية**: بمجرد عودة التغطية، يقوم التطبيق بمزامنة العمليات تلقائياً كل 30 ثانية دون أي تدخل بشري.
* **حماية التوقيت الصباحي القانوني**: يقبل السيرفر توقيت البصمة الفعلي (07:30 - 10:30) ولا يعتبر المفتش متأخراً عند المزامنة لاحقاً في منتصف النهار.
