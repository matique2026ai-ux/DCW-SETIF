# 🏛️ DCW-SETIF-TRACKER — منصة الرقابة والتفتيش الميداني
### مديرية التجارة الداخلية وضبط السوق الوطنية لولاية سطيف

منظومة إدارية ورقمية متكاملة لمتابعة فرق التفتيش والرقابة الميدانية، وضبط الحضور والانصراف الجغرافي الذكي، وإدارة البرامج الرقابية ومهام التفتيش، وتنظيم الفرق وتعيين رؤسائها، ومسار الاستفسارات القانونية وفق قانون الوظيفة العمومية، وتأشير المعاينات وتوليد التقارير الرسمية لحظياً.

## 👥 صلاحيات الأدوار التفصيلية

### 1. المسؤول التقني (`admin`)
> **مسؤول حصري عن إدارة الحسابات الرقمية — لا يُسجّل موظفين.**
* إنشاء حسابات النظام (`UtilisateursSysteme`) وتعيين الأدوار وكلمات المرور.
* تفعيل/تعطيل الحسابات وربطها بالسجل الإداري.
* التوليد التلقائي للحسابات الآمنة (Bulk Generation).
* ضبط فترة التسامح الصباحية المعتمدة.

### 2. المدير الولائي — الآمر بالصرف (`director`)
* **لوحة القيادة المركزية:** إحصائيات عامة وفورية (نشاط المفتشيات، المحجوزات، المخالفات).
* **الخريطة التفاعلية الحية:** تتبع لحظي عالي الأداء (60 FPS) لانتشار الفرق.
* **الفصل في الاستفسارات الإدارية:** قبول وحفظ / تنبيه إداري / إصدار قرار خصم نافذ.
* **تصدير التقارير الرسمية (PDF):** تقارير الحضور والمعاينات باللغة العربية.

### 3. رئيس المصلحة (`head_of_department`)
> **يدير مصلحته بالكامل من إلحاق الأعوان إلى تنفيذ المهام.**
* **إلحاق الأعوان:** استقطاب موظفين من خزينة المديرية وإلحاقهم بمصلحته.
* **تنظيم الفرق:** إنشاء الفرق وتعيين **رئيس الفرقة (Chef de Brigade)** من أعوانه.
* **أوامر المهمة:** إنشاء مهام تفتيشية مع تحديد:
  - 👑 **رئيس المهمة (Chef de Mission)**
  - 👥 **أعضاء الفرقة المرافقين**
  - 🚗 **وسيلة النقل**
  - 📍 **الدائرة، البلدية، نوع النشاط التجاري**
* **تأشير المعاينات:** مراجعة واعتماد محاضر التفتيش الميدانية رسمياً.

**المصالح المُدارة:**
- 🔴 **مصلحة حماية المستهلك وقمع الغش**
- 🔵 **مصلحة ملاحظة السوق ومراقبة الممارسات التجارية والمنافسة**

### 4. رئيس مكتب المستخدمين (`chef_bureau`)
> **مسؤول حصري عن تسجيل الموظفين الإداريين — لا يُنشئ حسابات رقمية.**
* **تسجيل الموظفين:** إدراج الأعوان في السجل الإداري (`Employes` + `TrackerEmployeeAdmin`).
* **متابعة التأخرات التراكمية:** احتساب وفق الأمر رقم 06-03 (قانون الوظيفة العمومية).
* **توجيه الاستفسارات الرسمية المطبوعة:** استمارة الاستفسار مع مهلة 48 ساعة.
* **تنفيذ قرارات الخصم:** تنفيذ قرارات المدير على كشف الراتب (`Exécuté sur Paie`).

### 5. المفتش / العون الميداني (`inspector`)
* **الحضور الذكي (GPS Geofencing):** بصمة جغرافية بلمسة واحدة — بدون سيلفي.
* **الرد على الاستفسارات:** تبريرات رسمية خلال 48 ساعة.
* **توثيق المعاينات:** المحل، المخالفة، الإجراء القانوني، المحجوزات + صور توثيقية.
* **المزامنة دون اتصال (Offline-First):** حفظ محلي ومزامنة تلقائية عند الاتصال.

## 🛠️ التقنيات المستخدمة (Tech Stack)

| الطبقة | التقنية |
|---|---|
| الواجهة الأمامية | Flutter 3.41.6 (Dart 3.11.4) — Provider |
| الخرائط | Flutter Map + LatLong2 (خرائط ESRI HD) |
| توليد PDF | pdf 3.12.0 + printing 5.14.3 |
| الخرائط القانونية | Geolocator + QR Flutter |
| الخادم الخلفي | Node.js / Express / RESTful API |
| قاعدة البيانات | PostgreSQL (سحابي) / SQL Server (محلي) |
| النشر | Render.com (Auto-Deploy on Git Push) |
